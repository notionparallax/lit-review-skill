# Publishable track (not yet built out)

The briefing track produces a review good enough to act on inside a practice. A review meant for peer review or a public audience needs more: a method a reviewer can audit, and evidence appraised for quality, not only recorded. This file lists what that track adds. It is an outline, to be developed; if a person asks for it now, explain that these stages are not yet written up in detail, agree with them which to do, and work carefully from the descriptions here.

## Choose a review type early

Decide in stage 2 (see Part A of [methods.md](methods.md)), because it sets the method. For publication, follow the reporting guideline for that type (SANRA for narrative, PRISMA-ScR for scoping, PRISMA 2020 for systematic) and say so in the method section.

## Additions, by stage

- **Stage 3.** Protocol agreed and dated before searching. Strings tested against a seed set for recall (share of known core sources each string finds), with a target (≈60% or better per concept) and each revision logged. A stopping rule for screening. A second database (Scopus or Web of Science).
- **Stage 4.** Screening reliability: the person screens a blind random sample and agreement is reported. A PRISMA-style flow diagram with counts. A coverage check: of the relevant records the search finds, what share the review already held, and which held sources the search misses and why.
- **Stage 5.** An extraction table (one row per empirical study: design, country, setting, sample, period, observed or reported, peer review, interest, finding, what it does not measure), and a concept matrix (study × concept). Quality appraisal with a recognised tool, such as MMAT (Hong et al., 2018) for mixed designs; a separate judgement of authenticity and informational value for theory, history and grey sources. The person extracts a random 10% independently, and the two versions are compared.
- **Stage 6.** A conceptual framework, figure and text, derived from the concept matrix.
- **Stage 8.** A mock peer review against the target journal's criteria, with a response log.
- **Stage 9.** A full claim audit. Every citing sentence is split into claims; independent checker agents find a verbatim supporting quote and page in the source's full text, with a verdict; a script confirms each quote really appears in the source; known errors are seeded into the sample blind, to measure how many the checkers catch. Then a methods supplement (search, screening, appraisal, audit, use of AI tools), a SANRA self-assessment, and an optional check of how much the cited sources cite one another (to show whether the review joins literatures that don't talk to each other).
